# My portfolio

I am Chukwujekwu Amanda Chimdiuso. I design and build websites, and I'm currently studying Advanced Diploma in Software Engineering at Aptech Nigeria, Lagos, Ajao Estate.

I made this site because I kept needing somewhere to send people when they asked
what I do, and a list of links was not really answering the question. So it is a
portfolio, but it is also the thing I point at when I say I can build this.

**It lives at [amanda-dev-bit.github.io](https://amanda-dev-bit.github.io/)**

## What it is made of

React and Vite, and plain CSS. No Tailwind, no component library, nothing for the
animation. I wrote the transitions myself because I wanted to know how they work,
not just how to install them.

Every bit of writing on the site sits in `src/data/`, so I can add a project or
rewrite my bio without going near a component.
